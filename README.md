# Python File Manager

Файловый менеджер на PyQt5. Приложение показывает содержимое выбранной папки, позволяет переходить по каталогам и просматривать поддерживаемые файлы во встроенной панели. Остальные файлы можно открыть в стандартной программе Windows.

## Стек

- Python 3.10+.
- PyQt5 5.15.11 и Qt Multimedia — графический интерфейс и встроенное аудио.
- pytest 8.4.2 — модульные тесты.

## Структура проекта

- `file_manager/main.py` — создание приложения и запуск главного окна.
- `file_manager/__main__.py` — точка входа для команды `python -m file_manager`; вызывает `main()`.
- `file_manager/ui/main_window.py` — главное окно и навигация.
- `file_manager/ui/preview_panel.py` — панель предпросмотра файлов.
- `file_manager/ui/main_window.ui` — приложенная форма для критерия задания; приложение её не загружает, интерфейс создаётся в Python-коде.
- `file_manager/services/file_formats.py` — реестр поддерживаемых типов файлов.
- `file_manager/services/file_reader.py` — чтение текстовых файлов.
- `tests/` — тесты реестра форматов, чтения, навигации, предпросмотра и открытия файлов.

## Установка и запуск на Windows

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m file_manager
```

После запуска выберите папку. Выбранный файл отобразится в панели предпросмотра. Кнопка «Открыть в Windows» запускает файл в стандартной для него программе.

## Возможности и ограничения

Встроенный просмотр поддерживает текстовые файлы и исходный код, Markdown, изображения и аудио. Список расширений находится в `file_manager/services/file_formats.py`. Видео внутри приложения не воспроизводится. Встроенное воспроизведение аудио зависит от доступных в Windows кодеков.

Предпросмотр текста ограничен 2 МБ; читаются UTF-8, UTF-16 с BOM и Windows-1251. Двоичные файлы не показываются как текст. Изображения уменьшаются до размера панели перед загрузкой, а Markdown может использовать изображения из той же папки.
