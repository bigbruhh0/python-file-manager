# Python File Manager

Файловый менеджер на PyQt5: показывает выбранную папку, позволяет переходить по каталогам, сразу показывает выбранный файл в панели предпросмотра и открывает его в стандартной программе Windows по кнопке.

## Стек

- Python 3.10+
- PyQt5 5.15.11 и Qt Multimedia — интерфейс и встроенное аудио; виджеты создаются в Python-коде
- pytest 8.4.2 — модульные тесты логики и навигации

## Запуск на Windows

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m file_manager
```

## Запуск тестов

```powershell
pytest
```

## Поддерживаемые форматы

Форматы собраны в `file_manager/services/file_formats.py`. Встроенный просмотр доступен для:

- Текста: `txt`, `log`, `csv`, `tsv`, `json`, `xml`, конфигурационных файлов и исходного кода.
- Markdown: `md`, `markdown`, `mdown`, `mkd`.
- Изображений: `png`, `jpg`, `jpeg`, `gif`, `bmp`, `webp`, `tif`, `tiff`.
- Аудио: `mp3`, `wav`, `ogg`, `oga`, `m4a`, `aac`, `flac`, `wma`.

Видео внутри приложения не воспроизводится: поддержка убрана из встроенного просмотрщика. Видео и любые другие файлы можно открыть кнопкой «Открыть в Windows». Встроенное воспроизведение аудио зависит от доступных Windows кодеков.

Предпросмотр текста ограничен 2 МБ, чтобы большие файлы не занимали чрезмерно много памяти. Читаются UTF-8, UTF-16 с BOM и Windows-1251; двоичные файлы не показываются как текст. Картинки уменьшаются до размера предпросмотра перед загрузкой. Markdown может использовать изображения из той же папки.

## Структура

- `file_manager/main.py` — создание приложения и запуск главного окна.
- `file_manager/ui/main_window.py` — главное окно, навигация и сборка интерфейса.
- `file_manager/ui/main_window.ui` — отдельно приложенная форма для критерия задания; приложение её не загружает.
- `file_manager/ui/preview_panel.py` — правая панель предпросмотра файлов.
- `file_manager/services/file_formats.py` — общий реестр типов и расширений.
- `file_manager/services/file_reader.py` — чтение текстовых файлов.
- `tests/` — тесты реестра форматов, чтения файлов, навигации, предпросмотра и кнопки открытия в Windows.
